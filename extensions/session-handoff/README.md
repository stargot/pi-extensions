# session-handoff

Автодамп состояния сессии при выходе и «подхватить с того места» при следующем запуске. Работает механически, без LLM: результат детерминированный и ничего не стоит.

## Как работает

- **При выходе** (`session_shutdown`) пишет `~/.pi/agent/handoff/<слаг-проекта>.md`: последний запрос пользователя, последний ответ ассистента, ветку git, `git status --short` (до 15 строк), хвост `git diff --stat`, три последних коммита, файл сессии и длительность. Хранятся 50 самых свежих файлов, старые удаляются.
- **При старте** (`startup` или `resume`) показывает уведомление, если для текущего каталога есть handoff.

## Команды

| Команда | Действие |
|---|---|
| `/handoff` | Показать handoff в прокручиваемом окне (TUI), вне TUI — уведомлением |
| `/handoff go` | После подтверждения отправить handoff модели как промпт продолжения |
| `/handoff clear` | Удалить handoff текущего проекта |

## Устройство

- `handoff.ts` — чистые функции: сборка markdown из готовых фактов, слаг проекта, обрезка строк. Покрыты тестами.
- `index.ts` — обвязка pi: чтение JSONL сессии, запуск git, события и команда.

Ошибки при записи handoff глушатся: дамп не должен ломать завершение сессии.
